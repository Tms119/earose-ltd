# Earose Industries Limited

Corporate website for Earose Industries Limited, an industrial packaging solutions and manufacturing provider.

**Live:** https://earoseltd.com

---

## Stack

- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
- **Routing & UI:** React Router DOM, Lucide icons, Framer Motion, Radix UI
- **Deployment:** Netlify

---

## Features

- Multi-page corporate site covering company profile, industrial services, and product catalog
- Interactive packaging product viewer with category navigation
- Contact and quote inquiry forms
- Fully responsive layout optimized for mobile and desktop viewing

---

## Run Locally

```bash
git clone https://github.com/Tms119/earose-ltd.git
cd earose-ltd/earose-ltd-main
npm install
npm run dev
```
